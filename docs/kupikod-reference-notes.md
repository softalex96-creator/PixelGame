# Reference notes — Kupikod study

Source reviewed: <https://kupikod.com/> on 18 August 2026. This file records structural and interaction observations only. It is not a source of copy, artwork, trade dress, icons, logos, game key art, or other assets for reuse.

## Observed commerce structure

The reference leads with a compact top navigation by purchase intent, then puts a full-width search input above promotional tiles. The central commercial pattern is a **fast top-up module**: users choose a service, enter an amount, select a display currency, optionally add a promotion code, and receive an immediately updated primary action. Trust labels and a curated row of popular services make this decision path visible before the longer catalog.

Below the conversion module, the reference groups merchandise into recommendations/discounts, a long game-currency directory with platform filters, games grouped by discovery intent, and service-wallet top-ups. Product cards use price, discount, game/service name, and artwork as concise comparison signals. Account benefits are presented after product discovery, not before it.

## PixelGame adaptation principles

PixelGame will retain its existing local-only simulated payment disclosure and will not claim official distribution, instant delivery, discounts, or availability unless those claims are substantively configured. The adapted homepage will use an original hierarchy: intent-led product families, a clear local preview configurator, a curated game-directory rail, compact offer cards, and a benefit strip. Its visual signature will be a dark "loadout console" surface with original abstract game-world artwork and custom line icons—not Kupikod's brand, tile artwork, layout geometry, or graphic assets.
