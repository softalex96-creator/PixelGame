# New cartridge drops — редакторские источники

Раздел **New cartridge drops** отделён от каталога PixelGame. Он не продаёт реальные игры, не содержит пользовательских оценок и не использует фальшивые отзывы. Карточки ссылаются на официальные страницы соответствующих игр; в интерфейсе использованы только краткие factual descriptions, проверенные 19 августа 2026 года.

| Игра | Фактическая основа карточки | Официальный источник |
|---|---|---|
| **Hades II** | Сиквел rogue-like dungeon crawler, где игрок сражается за пределами Подземного мира, используя тёмную магию против Titan of Time. | [Supergiant Games — Hades II](https://www.supergiantgames.com/games/hades-ii/) |
| **Split Fiction** | Кооперативное split-screen приключение для двух игроков; уровни чередуют научную фантастику и фэнтези, а Friend’s Pass позволяет пригласить второго игрока при соблюдении условий издателя. | [EA / Hazelight — Split Fiction](https://www.ea.com/games/split-fiction) |
| **Clair Obscur: Expedition 33** | Пошаговая RPG с механиками в реальном времени, вдохновлённая Belle Époque France; цель Expedition 33 — остановить Paintress. | [Clair Obscur: Expedition 33 — официальный сайт](https://www.expedition33.com/) |

> Редакторская формулировка «New cartridge drops» означает выбор команды PixelGame по различающимся игровым форматам, а не пользовательский рейтинг, отзыв или одобрение разработчиков указанных игр.
